# 主菜单背景
在加载这个世界时你可能已经注意到了：2.9 将带来 23 张全新的背景图片，全部直接取自 NASA/ESA！其中包括来自哈勃空间望远镜、詹姆斯·韦伯空间望远镜，以及最近的 Artemis II 载人绕月飞行任务的摄影作品！

随着这一改动，我们移除了插画/图库风格的背景，改用真实的太空摄影作品——但那张已陪伴本整合包 10 年的标志性 GTNH 菜单背景得以保留。

另外，主菜单本身也进行了一次小幅视觉改版，清晰度更上一层！
