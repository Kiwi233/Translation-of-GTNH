# 标题浮层
2.9 新增：部分标题与副标题文本显示效果已回移植到 1.7.10，供 GTNH 使用！服务器管理员现在可以使用 `/title` 在玩家的屏幕上显示标题与副标题文本。它还与你在聊天中可用的[完整颜色系统](./color_system.md)代码完全兼容！

标题还可以淡入、停留并淡出，各阶段时长可通过 `/title <player> times <fadeIn> <stay> <fadeOut>` 进行配置
