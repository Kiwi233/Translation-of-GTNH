# 电弧炉变更
作为 2.9 的一部分，围绕<Color id="GREEN">电弧炉</Color>的整套系统都发生了变化。我们不仅迎来了[工业电弧炉](../reworks/industrial_arc_furnace.md)，单方块机器也迎来了以下变更：

- 单方块等离子电弧炉现已<Color id="RED">__已弃用__</Color>，其配方映射已整合进主电弧炉
- 熟铁已更名为 __铸铁__ <ItemImage id="gregtech:gt.metaitem.01:13304"/>，且现在使用碳
- 在所有情况下，制作钢现在都需要煤炭
- 所有配方现在都有使用 __稀有气体__ 的替代配方（缩放方式与工业高炉相同）
- 下界合金配方全面下调了所属等级
- 静空奇点配方已下调等级
