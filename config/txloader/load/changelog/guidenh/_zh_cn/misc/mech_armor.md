# 机械装甲
<Color id="RED">机械装甲</Color>是一套全新的强力科技护甲，能够随你的进度共同成长！它最初于 HV 阶段制作，随着你在各电压等级间不断推进，可以解锁新的强化组件、框架与能量核心，变得越来越强大。

不同的框架拥有不同数量的 **移动**、**防护**、**实用** 与 **棱镜** 槽位，这决定了哪些类型的强化组件可以装入护甲！请明智地选择框架，充分利用这些关键槽位！

这套护甲预计将覆盖现有科技护甲（纳米套装、量子套装等）同等的范围与能力，并采用相近的等级划分

本指南不会深入讲解具体细节，这些就留待你在游玩过程中自行探索！
