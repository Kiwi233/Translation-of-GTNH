# 多方块诊断反馈
作为 2.9 更新的一部分，每个格雷科技多方块结构现在都会准确告诉你缺少哪些仓、总线、机械方块等（以及缺少的位置！）。如果所有机械方块都已放置，它会显示缺失的仓。如果缺少某个机械方块，它会告诉你该位置可以放置什么，并附有一个按钮，可在世界中高亮该方块！
