# 资源包更新通知器
我们知道你会装着资源包游玩，所以现在你有一个方便的游戏内更新通知器了！再也不用忍受那些在别处早已修复、你这里却依然损坏的材质了！

<Color id="GREEN">资源包更新检查器</Color>会查看你已启用的资源包，并在 GitHub 发布版本中检查是否有更新的兼容版本。这确实需要资源包作者主动加入该功能，不过一旦发现更新，你就会收到一条游戏内聊天消息，其中带有可点击的链接，指向最新的兼容版本！
