# 披风切换
你是否为整合包捐过款，或参与过它的开发？那么……<Color id="GREEN">__谢谢你！！__</Color>

现在可以在游戏内使用 `/cape` 命令切换披风了！你的选择随后会保存在客户端上，因此不必担心要在每个不同的世界里重复更改。如果你觉得自己本该有披风却没有，请在 [Discord](https://discord.gg/gtnh) 上联系我们
