# 现代化 Tab 列表
现代风格的“Tab 列表”（玩家列表）已被向后移植，让服务器游玩体验更加顺滑！通过自定义服务器上的 `serverutilities.cfg`，你现在可以配置：
- 玩家头像
- Ping 数值
- 动态列
- 页眉与页脚
