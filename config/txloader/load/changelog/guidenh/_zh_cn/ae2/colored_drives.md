# 颜色编码的ME驱动器
ME驱动器的视觉渲染方式发生了变化！现在为驱动器上色时，颜色会应用于外壳本身，而不是其中各个独立的驱动器！

这样你既能维持按颜色分类的存储系统，又能在不打开GUI的情况下分辨内部存储元件的类型与等级！
