# CPU排序
是否曾希望排序CPU时不必局限于仅按名称排序？现在可以了！

现在CPU可以按以下多种指标排序：
- CPU名称
- 存储内存
- 协处理器数量
- 合成状态
- 自动化（玩家、混合、非玩家）

并且在上述任何类别上都可以按升序或降序排序！
