# 游戏内信息切换
<Color id="GREEN">InGame Info</Color>（默认位于左上角的信息）现在支持第二个配置文件了！

这意味着你可以保存两套不同的 HUD 布局，并在游戏中随时切换！

添加一个可选的第二个文件（`\config\InGameInfo2.xml`），然后使用切换键循环切换：主配置 -> 副配置 -> 关闭！
