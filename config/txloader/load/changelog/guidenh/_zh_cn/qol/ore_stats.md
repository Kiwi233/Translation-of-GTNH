# 矿石改动
矿石的生成方式以及玩家与矿石的交互方式有几项不错的改动！概述如下
# 矿脉信息页面

    全新的“矿脉信息”页面

NEI 中的 <Color id="GREEN">矿脉信息</Color> 页面迎来了一次漂亮的翻新！涵盖“矿脉信息”、“贫瘠矿石信息”和“地下流体信息”页面。

除了焕然一新的外观，悬停在一个包含该矿石的世界（维度）上时，还会显示该矿脉在该世界每个含矿区块中的生成几率！

新页面仍保留了旧版设计中的全部信息，而且如果你的 GUI 缩放允许，现在还能在一个常规页面中显示不止一种矿脉类型。

来自 __BartWorks__ 等模组的矿石也经过重构，改用同一系统。再也不用担心搜索不同矿石时出现奇怪的表现。

# 矿石生成改动
- <Color id="GREEN">Bartworks</Color> 和 <Color id="RED">GT++</Color> 生成的矿石现已重做，以模仿格雷科技矿脉的生成方式
- 小行星更加常见，但作为补偿，现在体积更小
- 小行星带中新增了 <Color color="#DBF1FD">冰小行星</Color>
- 矿脉现在更不容易被空气抹除
- 一些缺失的矿脉已加入 NEI，方便查找并保持一致性
