# 特斯拉电塔 GUI
<Color id="GREEN">特斯拉电塔</Color>现在配备了一个功能繁多、非常实用的 GUI！
- 用于管理你所有参数的全新面板
- 实时负载条，显示当前吞吐量
- 可配置的负载随时间变化图表
- 热力图，帮你找出耗电最多的特斯拉用电设备

GUI 里的功能点实在太多，无法在此一一详述，快去亲自实验吧！
