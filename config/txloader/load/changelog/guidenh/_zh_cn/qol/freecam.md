# 自由视角
2.9 现在带来了 Freecam（自由视角）模组！对所有想找到完美角度、展示自己最新建筑狂想之作的炫耀达人来说再合适不过！

## 功能特性：
- 创造与静止（不漂移）两种移动选项
- 摄像机碰撞箱小于半格，甚至能钻进半砖下方
- <Color id="GREEN">三脚架系统</Color>：按住 _切换_ 键并按下数字键即可保存摄像机位置
- 四种碰撞模式：
- - 完全碰撞
- - 忽略透明方块（非不透明方块）
- - 忽略可开启方块（门、活板门等）
- - 无（无碰撞）
- 提供全亮、去除迷雾、手部渲染和初始视角的配置选项

## 默认操作：
- F4 - 切换自由视角（当前绑定：<KeyBind id="key.freecam.toggle"/>）
- F4 + 1-9 - 打开或切换到 <Color id="GREEN">三脚架</Color> 槽位（当前绑定：<KeyBind id="key.freecam.toggle" /> + 1-9）
- F4 + C - 切换玩家/摄像机控制（当前绑定：<KeyBind id="key.freecam.playerControl" />）
- F4 + R - 重置所有 <Color id="GREEN">三脚架</Color>（当前绑定：<KeyBind id="key.freecam.resetTripods" />）
- 滚动鼠标滚轮 - 调整飞行速度
> [!NOTE]
> 服务器管理员可以强制指定碰撞模式，或为玩家彻底禁用该模组
