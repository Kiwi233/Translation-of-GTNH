# 虚空采矿场筛选

你是否曾觉得，为了筛选你那一整排 <Color id="RED">虚空采矿场</Color>，而要把特定矿石逐个加进输入总线，这个过程十分繁琐？

现在，这一切都可以通过虚空采矿场自身的一个界面全部完成！

打开新界面后，你可以按需切换当前维度掉落池中的每一种矿石。此改动还新增了：
- 无需再使用烦人的老式螺丝刀，即可在黑名单与白名单模式之间切换
- 使用 <Color id="GREEN">闪存</Color> 复制与加载过滤配置
- 按名称搜索并高亮矿石
- 通过一个专门按钮添加或移除 __所有__ 矿石

> [!NOTE]
> 这个新界面与现有设置完全兼容：输入总线中的矿石 __或__ 在界面中选中的矿石都会被纳入过滤
