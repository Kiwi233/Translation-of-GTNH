# 现场工程师工具箱
作为统一化改动的一部分，现在有了全新改进的 <Color id="GREEN">现场工程师工具箱</Color> <ItemImage id="gregtech:gt.Item_Toolbox" />

这是工业时代2（IC2）工具盒的直接升级版，带来了许多令人兴奋的新功能！

它为你的所有工具提供了专属槽位，还有一个专门的电池槽，让你可以随时随地充电！只要电池装在里面，你也可以在机器中为整个工具箱一次性充电。

另有六个额外槽位，用来放置任何你想随手取用的东西！<Color id="BLUE">电烙铁</Color>会从这些槽位中取出焊接材料。

按下 _<KeyBind id="key.pickItem" />_（默认：鼠标中键）会打开一个环形菜单，供你选择一件工具。这让你可以 _在不把工具从工具箱中取出的情况下_ 使用它。工具箱会表现得如同已装备了那件工具，所有耐久损耗与电量消耗都会直接结算到正在使用的工具上！

当你注视着一个需要相应工具的方块并按下 _<KeyBind id="key.pickItem" />_（默认：鼠标中键）时，只要该工具存放在工具箱中，就会直接装备它，跳过环形菜单！例如，注视 <Color id="GREEN">锡线缆</Color> 时，它就会装备你存放的剪线钳。

右键点击维护仓即可将其修复，方式与最初的 IC2 工具盒相同。

更改编程电路 <ItemImage id="gregtech:gt.integrated_circuit" /> 时，即使螺丝刀没有装备在手上，也会自动在工具箱中寻找螺丝刀！

具有“模式”的工具（例如扳手上的 <Color id="BLUE">直线模式</Color>）只要已装备，就可以直接从工具箱本身进行切换。
