# 组合快捷键
你喜欢把每个快捷键都一次设置到位，却讨厌依赖 NUMPAD= 这类奇怪按键吗？还是你的键盘是小尺寸紧凑型，按键根本不够应付所有新选项？

现在这些都已成为过去，因为我们有了组合快捷键！这大大增加了你同时能拥有的 __合理__ 快捷键数量！

    一些组合快捷键的示例！

> [!NOTE]
> 组合快捷键在界面（GUI）中无法使用。这是 GUI 内部处理顺序所导致的一种限制，很遗憾无法避免
