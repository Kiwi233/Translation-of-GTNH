# 覆盖板改动
格雷科技机器及其管道、线缆的 <Color id="GREEN">覆盖板</Color> 使用方式有以下几项改动，概述如下

# 拆卸机器上的覆盖板
有时候，最小的改动反而感觉最明显！

现在破坏带有覆盖板的方块时，若按住 Shift 进行破坏，覆盖板会随之掉落。直接破坏则保持原有行为

# 染色玻璃覆盖板
有没有想过把 **染色玻璃**（或其他半透明覆盖板）装到管道和机器上？现在可以了！

用你喜欢的颜色的染色玻璃合成一块 AE2 面板，然后把它装在：
- 管道
- 线缆
- 框架
- 机器
