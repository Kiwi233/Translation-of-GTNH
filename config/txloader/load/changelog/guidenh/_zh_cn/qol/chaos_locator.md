# 混沌定位器
许多后期玩家都知道，飞到混沌守卫（Chaos Guardian）的所在地是一段漫长而痛苦的旅程，更别提到达那里会生成的数百个区块了！

混沌守卫总是生成在 <Color id="RED">混沌岛</Color> 上，这些岛屿的 x 和 z 坐标都是 10,000 的倍数（例如 x=10,000、z=0）。有了 <Color id="GREEN">混沌定位器</Color> <ItemImage id="gregtech:gt.Item_Chaos_Locator" />，这个问题已成过去！

只需使用该物品，玩家就可以在界面中输入 x 和 z 两个数字，随后会被传送到 (10,000 x X-Coord , 10,000 x Z-Coord)，从此不再痛苦（除了在那里等着你的那头怪物……）

这甚至支持跨维度使用！
