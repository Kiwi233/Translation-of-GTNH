# 显示元件

<ItemImage id="appliedenergistics2:item.ItemViewCell" scale="2" />

显示元件用于过滤[终端](terminals.md)的显示内容。可在<ItemLink id="appliedenergistics2:tile.BlockCellWorkbench" />（元件工作台）中设置其过滤规则，再放入终端，即会仅显示匹配的物品。多个显示元件的过滤效果为叠加模式。
