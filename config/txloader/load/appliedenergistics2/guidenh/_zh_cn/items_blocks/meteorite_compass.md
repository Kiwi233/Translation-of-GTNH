# 陨石罗盘

<ItemImage id="appliedenergistics2:tile.BlockSkyCompass" scale="4" />

陨石罗盘会指向含有[陨石](../ae2_mechanics/meteorites.md)的区块，包括人造陨石。若当前区块中就有陨石，指针会快速旋转；附近没有陨石时，指针则缓慢旋转。
