# 样板优化矩阵

<BlockImage id="appliedenergistics2:tile.BlockPatternOptimizationMatrix" scale="4" />

样板优化矩阵是本分支用于优化样板的网络设备。将它接入网络后，合成确认界面即可提供样板优化；同时接口中还必须启用**允许样板优化**。

它需要占用1个频道，并且可以像其他网络设备一样放置在ME网络中。
