# 扳手工具

<Row>

  <ItemImage id="appliedenergistics2:item.ToolNetherQuartzWrench" scale="4" />

扳手用于旋转AE2设备（右键点击）和拆卸AE2方块（Shift+右键点击）。可单独移除[线缆子部件](../ae2_mechanics/cables_subparts.md)而不影响整体线缆结构。许多AE2方块支持旋转，即使文档未明确说明也可尝试。
