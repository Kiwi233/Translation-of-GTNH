# 内存卡

<ItemImage id="appliedenergistics2:item.ToolMemoryCard" scale="4" />

内存卡可在AE2[设备](../ae2_mechanics/devices.md)之间复制配置、链接[P2P通道](p2p_tunnels.md)，并将[升级卡](upgrade_cards.md)粘贴到设备上。

* Shift+右键点击可复制配置，或生成新的P2P链接频率
* 右键点击可粘贴配置、升级卡或绑定P2P链接频率
