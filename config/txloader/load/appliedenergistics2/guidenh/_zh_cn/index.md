# 应用能源2是什么？

应用能源2添加了一些组件与机制，为物流与存储问题提供解决方案。你可以把那间
堆满箱子的大房间替换成紧凑的ME网络，但这仅仅是开始。
应用能源设计了与整合包中的其他模组的联动，可以实现自动化。你可以把系统设置为：
只需轻轻一点，就能合成复杂合成链中所有必要的前体（以及终产物），或是维持一定
数量的物品库存、在需要时合成更多，抑或仅仅是在你的基地里传输物品。
